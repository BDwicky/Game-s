Portal game arcade web modern dan responsif yang menghadirkan koleksi **7 game arcade klasik & modern**, dilengkapi dengan sistem leaderboard global, kustomisasi skin, serta dukungan Progressive Web App (PWA) untuk perangkat mobile dan desktop.

🌐 **Mainkan Sekarang:** [https://game.dwicky.dev/](https://game.dwicky.dev/)

---

## 🕹️ Koleksi Game

| Game | Deskripsi | Fitur |
| :--- | :--- | :--- |
| **🔢 2048** | Puzzle geser angka untuk mencapai ubin 2048. | High-score tracking & animasi halus. |
| **🐦 Flappy Bird** | Navigasi burung melewati rintangan pipa. | Dynamic atmosphere themes, collectible stars, & skin selector. |
| **🐍 Snake Neon** | Game ular klasik bergaya neon cyber. | Responsive touch/keyboard arena & visual neon modern. |
| **🟡 Pacman** | Jelajahi labirin arcade legendaris menghindari hantu. | Classic arcade sound & responsive control pad. |
| **🧱 Tetris** | Susun balok yang jatuh untuk menghapus baris. | Smooth drop physics & level progression. |
| **🃏 Memory Game** | Tantangan mencocokkan pasangan kartu bergambar. | Timer & move counter challenge. |
| **❌ X O X** | Permainan adu strategi klasik Tic-Tac-Toe. | Quick match mode. |

---

## ✨ Fitur Utama

- 🏆 **Live Global Leaderboard**: Papan peringkat skor tertinggi untuk setiap game.
- 🔐 **Profil Pemain**: Sistem login instan dengan PIN 6-digit dan fitur pemulihan akun.
- 🎨 **Kustomisasi Skin**: Pilihan skin karakter pada game arcade.
- 📱 **PWA & Mobile-First**: Tampilan responsif dengan dukungan mode Fullscreen dan instalasi ke layar utama perangkat (Home Screen).

---

## 🛠️ Teknologi

- **Frontend:** HTML5, CSS3 (Modern Glassmorphism & Neon Arcade Theme), Vanilla JavaScript (ES6+), PWA (Service Worker)
- **Backend:** PHP & SQLite

---

## 🚀 Menjalankan Secara Lokal

Untuk mencoba di komputer lokal:

1. Clone repositori:
   ```bash
   git clone https://github.com/BDwicky/Game-s.git
   cd Game-s
   ```
2. Jalankan server lokal (misalnya menggunakan PHP built-in server):
   ```bash
   php -S localhost:8000
   ```
3. Buka `http://localhost:8000` pada browser Anda.
