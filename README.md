# 🎮 Game Hub

[![Live Demo](https://img.shields.io/badge/Demo-game.dwicky.dev-00ffcc?style=for-the-badge&logo=google-chrome&logoColor=black)](https://game.dwicky.dev/)
[![Platform](https://img.shields.io/badge/Platform-Web%20%7C%20PWA-orange?style=for-the-badge)](https://game.dwicky.dev/)

A modern, responsive web arcade portal featuring **7 classic and modern games** with real-time global leaderboards, customizable player skins, 6-digit PIN authentication, and Progressive Web App (PWA) support for both mobile and desktop devices.

🌐 **Play Now:** [https://game.dwicky.dev/](https://game.dwicky.dev/)

---

## 🕹️ Games Collection

| Game | Description | Highlights |
| :--- | :--- | :--- |
| **🔢 2048** | Classic sliding tile puzzle to reach the 2048 tile. | High-score tracking & fluid animations. |
| **🐦 Flappy Bird** | Tap to navigate through pipe obstacles. | Dynamic score-based atmospheric themes, collectible stars, & skin selector. |
| **🐍 Snake Neon** | Cyber-neon twist on the classic snake game. | Responsive arena controls, zoom-center view, & modern neon visuals. |
| **🟡 Pacman** | Navigate the legendary maze avoiding ghosts while eating pellets. | Authentic retro arcade sound & responsive touch control pad. |
| **🧱 Tetris** | Rotate and drop blocks to clear lines and level up. | Smooth drop physics, level progression, & line clear counter. |
| **🃏 Memory Game** | Test and sharpen memory by matching paired cards. | Timed challenges & move counter. |
| **❌ X O X** | Quick tactical matches of classic Tic-Tac-Toe. | Instant gameplay & fast match restarts. |

---

## ✨ Key Features

- 🏆 **Global Live Leaderboards**: Real-time high-score tracking and rankings for every game.
- 🔐 **Player Profiles**: Quick sign-in with 6-digit PIN and security question recovery.
- 🎨 **Skin Customization**: Unlockable and selectable character skins for arcade titles.
- 📱 **PWA & Mobile-First**: Responsive layout with touch gesture support, offline caching, and an immersive Fullscreen Mode.

---

## 🛠️ Built With

- **Frontend:** HTML5, CSS3 (Modern Glassmorphism & Neon Arcade UI), Vanilla JavaScript (ES6+), PWA (Service Worker)
- **Backend:** PHP & SQLite
